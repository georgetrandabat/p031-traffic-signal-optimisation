P031 COMMANDS

Run the SUMO commands from scenarios/cross4/
Run the Python commands from the project root


1. MAKE THE FILES
Write the .nod, .edg, .con, .rou, .add and .sumocfg files by hand, or draw the road visually:

    netedit


2. COMBINE THEM INTO A NETWORK

    netconvert -c cross4.netccfg

Builds cross4.net.xml from the .nod, .edg and .con files.
Rerun it whenever you change one of those three.
Changes to .rou, .add or .sumocfg files don't need it.


3. RUN A SCENARIO

    sumo-gui -c s1_moderate_equal.sumocfg     (with the visual window)
    sumo -c s1_moderate_equal.sumocfg         (no window, faster)

Options you can add to a run:

    sumo -c s1_moderate_equal.sumocfg --seed 3 --end 300

    --seed 3    use a different random pattern of traffic
    --end 300   stop after 300 s, handy for a quick test


4. COLLECT RESULTS AND MAKE CHARTS

    python analysis/collect_results.py              all scenarios, 5 seeds, writes results.csv and summary.csv
    python analysis/collect_results.py --no-run     re-read existing outputs, without running SUMO
    python analysis/plot.py                         summary.csv to charts in analysis/plots/
